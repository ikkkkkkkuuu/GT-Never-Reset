# GT-Never-Reset 0.1.0

首个正式发行版本，面向 Minecraft 1.7.10 / Forge 的 GT New Horizons 附属模组。

## 主要内容

- ME 无线二合一接口终端、无线频率卡、高级 IO 总线与库存 IO 接口。
- 通配样板、样板输入仓室及镜像、量子合成与循环样板诊断。
- 装配矩阵、保险库、大型矿石处理机、大型熔炉及参数控制模块。
- GTM 风格的小型搅拌机、电解机、化学反应釜与离心机，覆盖 LV 至 UV，共 32 台，支持独立流体槽及多流体 NEI 布局。
- 碎片世界采集器、末晶谐振器与稳定末影水晶。
- 通量插头与通量点、多方块结构和性能提示，以及默认关闭的全局配方加速设置。
- 整理物品、TileEntity、渲染及代理代码职责，并补充主要功能的图文说明。

## 下载与安装

将 `gtneverreset-0.1.0.jar` 放入整合包的 `mods` 目录。`-dev`、`-sources` 和 `-predowngrade` 文件用于开发，不是普通安装包。

开发与构建基准为 GTNH `2.9.0-RC-2`、Minecraft `1.7.10`、Forge `10.13.4.1614`；其他 GTNH 版本的兼容性尚未验证。

功能使用说明和截图见 [README](https://github.com/ikkkkkkkuuu/GT-Never-Reset/blob/0.1.0/README.md)。第三方代码与资源的署名、来源及许可证随模组保留在 `META-INF` 中。
