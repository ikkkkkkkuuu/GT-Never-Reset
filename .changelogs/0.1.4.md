# GT-Never-Reset 0.1.4

## 新增与调整

- 新增 CropsNH 作物与种子增强：作物在生长判定时直接成熟，种子的生长、产量和抗性固定为 31，作物必定返回一粒种子。
- 三项增强均默认开启，可在 `cropsnh` 配置分类中分别关闭。

## 下载与安装

使用 `gtneverreset-0.1.4.jar` 替换旧版模组 JAR，避免同时安装多个版本。`-dev`、`-sources` 和 `-predowngrade` 文件用于开发。

开发与构建基准为 GTNH `2.9.0-RC-2`、Minecraft `1.7.10`、Forge `10.13.4.1614`；其他 GTNH 版本的兼容性尚未验证。
