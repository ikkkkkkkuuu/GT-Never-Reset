# GT-Never-Reset 0.1.1

## 新增功能

- 大型蜜蜂杂交机：物种档案、多步杂交路线、可杂交蜂种筛选，以及按电压和参数模块调整的并行处理与批次进度显示。
- 封包供应器、无线连接器和专用核心，支持神秘时代、血魔法及 GT 装配线等加工流程。
- 无线电网监控 HUD，显示团队 EU 余额、瞬时净流量与五分钟平均值，并提供位置、样式和刷新设置。
- R 键轮盘菜单与工具腰带。
- 客户端隐藏 Windows 任务栏按钮的设置。

## 调整与修复

- 将接口搜索自动填充开关移入无线二合一接口终端界面，移除对应的 NEI 设置项。
- 恢复大型矿石处理机对无法处理原料的批量转移。
- 调整多方块 GUI 主题，分行显示末晶谐振器的电压、电流与发电量。
- 统一添加者署名特效，并将相关机器功能说明迁移到 Java 翻译注释流程。
- 游戏启动时隔离生成的运行时 JAR，避免同时构建覆盖运行中客户端或服务端正在读取的文件。

## 下载与安装

使用 `gtneverreset-0.1.1.jar` 替换旧版模组 JAR，避免同时安装多个版本。`-dev`、`-sources` 和 `-predowngrade` 文件用于开发。

开发与构建基准为 GTNH `2.9.0-RC-2`、Minecraft `1.7.10`、Forge `10.13.4.1614`；其他 GTNH 版本的兼容性尚未验证。
