# GT-Never-Reset 0.1.16

适用于 GTNH 2.9.0。请同时安装 `gtneverreset-0.1.16.jar` 和 `gtnrlib-0.1.14.jar`，替换旧版对应文件。

- 更新高级 IO 总线的界面与数量设置窗口，接入共享主题，更新使用说明和截图。
- 调整无线频率卡、无线电力卡和通配样板界面，更新无线电力传输与交互逻辑。
- 调整作物育种机的界面、育种逻辑和提示。
- GTNRLib 新增 AE2 明暗主题与纹理，更新轮盘、下拉框、物品槽和开关等共享控件。
