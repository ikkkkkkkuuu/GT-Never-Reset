# GT-Never-Reset 0.1.13

## 安装

同时安装 `gtneverreset-0.1.13.jar` 与 `gtnrlib-0.1.12.jar`，替换旧版对应文件。本次公共库新增共享 GUI 控件并调整 coremod 入口，需要更新。

构建基准：GTNH 2.9.0、Minecraft 1.7.10、Forge 10.13.4.1614。

## 更新

- 新增大型作物育种机、配置和对应操作界面。
- 新增昆虫法杖及其配置界面、渲染和相关兼容逻辑。
- 调整大型养蜂机的结构、等级、育种规划和操作界面。
- GTNRLib 新增分支进度控件，调整 early coremod 入口位置。
- 整理机器处理、ME 样板、量子合成和终端逻辑的职责目录，改进相关状态与事务处理。
- 补充封包供应器使用说明、MUI2 GUI 指南、截图、测试夹具及来源许可记录。
- 调整构建产物目录，避免将主模组的中间处理 JAR 上传为发行附件。
