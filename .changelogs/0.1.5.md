# GT-Never-Reset 0.1.5

## 调整与修复

- GT 工具合成耐久消耗默认除以 10，向上取整且至少消耗 1；可通过 `tools.craftingDurabilityMultiplier` 调整，设为 1 恢复原消耗。挖掘和攻击不受影响。
- 合成容器物品查询使用工具副本，避免修改调用方工具的数量和 NBT。
- 大型矿石处理机禁用维护检查。

## 下载与安装

使用 `gtneverreset-0.1.5.jar` 替换旧版模组 JAR，避免同时安装多个版本。`-dev`、`-sources` 和 `-predowngrade` 文件用于开发。

开发与构建基准为 GTNH `2.9.0-RC-2`、Minecraft `1.7.10`、Forge `10.13.4.1614`；其他 GTNH 版本的兼容性尚未验证。
