# GT-Never-Reset 0.1.12

## 安装

同时安装 `gtneverreset-0.1.12.jar` 和 `gtnrlib-0.1.11.jar`，替换旧版对应文件。本次公共库新增指令树与聊天补全，并修复文字渲染，需要更新。

构建基准：GTNH 2.9.0、Minecraft 1.7.10、Forge 10.13.4.1614。

## 更新

- GTNRLib 新增指令树同步、权限过滤及聊天命令补全，修复 Angelica 文字特效边缘采样。
- 更新量子合成规划算法，补充数量溢出、循环、种子预留和计划回放检查。
- 超载供应器支持多流体输入，改进普通库存投料及 GT / Modern 机器流体产物回收。
- Modern 流体机器按目标可用空间自动输出，移除单次 1000 mB 限制。
- 高级 IO 总线新增“仅向机器输入”选项，并调整状态图标。
- 矿石处理厂并行与线程数随电压等级增长，提示显示线程加成。
- 修复 Et Futurum 高炉矿辞注册时序；调整养蜂机配方，新增创造维护仓和二极管配方。
- 调整 Windows Gradle socket 临时目录，补充测试夹具、许可记录及辅助工具。
