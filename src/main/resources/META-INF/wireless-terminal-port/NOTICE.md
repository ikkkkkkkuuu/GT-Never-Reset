Adaptations preserve the combined native AE2 interface/pattern terminal while
moving the item, container, client screens, packets, recipes, state and loaders
into GT-Never-Reset's responsibility packages. Mod resource locations and
translation keys use `gtneverreset`. The legacy AE2Thing inventory, GUI and
network registries were replaced with direct native AE2 integration. Upgrade
recipes preserve terminal NBT and accept either ingredient order while rejecting
additional occupied slots.
