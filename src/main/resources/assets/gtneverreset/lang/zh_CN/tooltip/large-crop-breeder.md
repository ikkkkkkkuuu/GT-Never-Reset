自动规划 CropsNH 确定杂交配方，支持二至四亲本与多步路线
首次投入已分析的 CropsNH 种子时，消耗一颗并永久保存其品种和属性
档案亲本可重复用于杂交；同品种的后续种子不会自动入档或覆盖属性
成功杂交的中间作物自动入档，同时输出一颗种子；目标作物持续按配方繁育
GUI 提供运行、亲本档案、可育作物和杂交路线四页；支持搜索与 NEI 拖入目标，轮换显示可替代基土
路线页以亲本谱系图显示多步杂交；支持拖动、滚动、Ctrl + 滚轮缩放及中键重置
可育列表表示亲本可达，实际运行仍需满足电压、肥料和催化剂要求
只使用 CropsNH 的确定机器杂交配方，不执行世界专属杂交或随机杂交池

保留原配方最低电压、基础耗时与能耗，每升一级电压执行普通四倍能耗、两倍速度超频
杂交成功率由结果作物决定，与电压无关；GUI 显示当前步骤、路线结果及作物的成功率
默认作物等级 1–3 / 4–6 / 7–9 / 10–12 / 13–15 / 16+ 对应 100% / 80% / 60% / 40% / 20% / 10%
可在 machine.cfg 的 crop_breeder 分类修改等级分档概率，并按作物 ID 单独覆盖；重启生效
失败仍消耗本轮催化剂与肥料，基土保留；不产出种子，也不解锁作物档案
基土放在输入总线中，仅检测、不消耗，可重复用于杂交；同组基土任选一种，不同组均需满足
没有额外基土要求时，以作物支持的种植土壤作为基土；GUI 轮换显示可选土壤
其他催化剂仍按原配方消耗，输入仓提供富集肥料
肥料消耗采用 CropsNH 原公式，种子属性为所有亲本属性的平均值，向下取整
遵循模组已有的 CropsNH 满属性配置；开启时种子属性仍固定为 31/31/31
输出空间不足时不开始新一轮，完成前输出堵塞则暂停等待；支持区块卸载和存档恢复
不支持并行、批处理或参数模块
