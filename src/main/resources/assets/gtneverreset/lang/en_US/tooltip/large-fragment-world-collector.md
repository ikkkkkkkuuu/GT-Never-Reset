Install multiple Fragment Dimension Hatches with one dimension marker in each to collect from several dimensions at once. The collector takes turns starting recipes from each dimension and selects circuits and page markers automatically.
A compatible drill head in an input bus switches the entire collector to fluid collection. It uses the available drill with the lowest wear rate.
With no dimension hatches installed, use separate input buses or ME patterns to run different dimension markers and circuits at the same time.
Higher supply voltage does not shorten recipes. Additional power can run more threads.
