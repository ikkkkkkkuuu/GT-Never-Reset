Supply the net ingredients listed in NEI for a single batch of finished products.
Recycled materials offset consumption. Supply only the net materials consumed per batch.
Each batch uses the highest native EU/t. Duration is calculated from the total native energy. Chanced outputs contribute their expected yields.
Routes retain the native furnace heat requirements. Monazite also requires a clear muffler exhaust.
The main ring uses robust tungstensteel machine casings and unlocks platinum-group and rocket fuel processing. The second ring uses LuV vacuum casings and unlocks rare-earth and indium processing. The third ring uses ZPM basic photolithographic framework casings and a muffler, unlocking monazite and polybenzimidazole (PBI) processing.
The fourth ring uses UV radiant naquadah alloy casings. Install a field restriction coil of the required tier to refine naquadah fuel. With Et Futurum Requiem installed, this ring also unlocks netherite processing.
Set the trigger stack size to select a ring count for hints and assisted construction.
