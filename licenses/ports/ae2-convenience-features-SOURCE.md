# Crafting completion rows

Adapted from zeroCNM/AE2-Convenience-Features 0.11, commit
71319f55edc6f4c2ee344f6d0f78f04afa654f8c. The port covers the crafting
completion history and its temporary terminal rows. It uses GT-Never-Reset's
packet channel, the current GTNH AE2 interfaces, and the six-column combined
terminal layout.

https://github.com/zeroCNM/AE2-Convenience-Features/tree/71319f55edc6f4c2ee344f6d0f78f04afa654f8c
