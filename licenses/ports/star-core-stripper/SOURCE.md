# Star Core Stripper

The geometry and machine parameters come from GTL Enhancedcore 3.8.0 in the supplied GregTech Leisure instance. The upstream project is [GTL-Enhancedcore](https://github.com/hongshaotimo/GTL-Enhancedcore). Its LGPL v3 license is included alongside this record.

The installed mod resolves the structure through its hollow structure manifest. The imported resource is `data/gtl_enhancedcore/structures/hollow/star_core_stripper.pattern.gz`. The decompressed UTF-8 pattern has SHA-256 `f25749c501c7af3a137c705af8dd4709e8272c92b9d3009be0cb1a309b702b54`. Dimensions are 123 × 123 × 73 (width, height, depth). MBS1 rows run from the top down and aisles from the front towards the back, reversing GTCEu's UP and FRONT axes. The controller changes from C to ~ at offset (61, 11, 2). All other characters, including spaces, are preserved.

The 1.7.10 controller uses GTNR recipe threads, parameter hatches and the existing fragment collection map. The GTNH structure uses advanced iridium-plated casings, Mk III fusion casings, fusion coils, radiant naquadah alloy casings, tungstensteel pipe casings, neutronium-coated glass and color-matched Chisel Anti Blocks (stained glass when unavailable). The UHV assembly line uses four GTNR fragment collectors in place of the source pack's four large collectors.
