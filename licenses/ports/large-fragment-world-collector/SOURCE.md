# Large Fragment World Collector

The structure pattern and processing multipliers are adapted from [GTLCore](https://github.com/GNSW/GTLCore) at commit `b6f3c1ecf04165d6445a570830a45a9bed8ee0f8`. The upstream LGPL version 3 license is included in `LICENSE.txt`.

The source pattern is `LARGE_FRAGMENT_WORLD_COLLECTION_MACHINE` in [MultiBlockMachineBStructure.java](https://github.com/GNSW/GTLCore/blob/b6f3c1ecf04165d6445a570830a45a9bed8ee0f8/src/main/java/org/gtlcore/gtlcore/common/data/machines/structure/MultiBlockMachineBStructure.java). The GTNR MBS1 resource preserves the 3 × 7 × 3 geometry. It reverses the source rows and aisles, converts wildcard `A` to a space, and converts controller `S` to `~` at offset (1, 3, 0). The resource stores horizontal layers from top to bottom. The controller transposes them into front-to-back aisles for StructureLib.

The [upstream controller definition](https://github.com/GNSW/GTLCore/blob/b6f3c1ecf04165d6445a570830a45a9bed8ee0f8/src/main/java/org/gtlcore/gtlcore/common/data/machines/MultiBlockMachineB.java) uses one energy input, fixed item bus positions, 64 parallel operations, a duration multiplier of 0.25, and an energy multiplier of 256. The GTNR controller uses stable titanium casings, permits additional item inputs and fluid I/O in casing positions, and uses 64 independent recipe threads on the GTNR fragment collection recipe map. The GTNR port is available in normal worlds and reuses the existing small collector's front overlays.

The GTNR controller recipe preserves the original 3 × 3 pattern, IV circuits, EV field generators, small collector and tungstensteel gearboxes. It uses the same substitutes for the two skyblock crystals as GTNR's small collector, an LV sensor for the treasures crystal and an LV emitter for the mining crystal. The original recipe is declared in [SkyTearsAndGregHeart.java](https://github.com/GNSW/GTLCore/blob/b6f3c1ecf04165d6445a570830a45a9bed8ee0f8/src/main/java/org/gtlcore/gtlcore/data/recipe/processing/SkyTearsAndGregHeart.java#L321-L327).
