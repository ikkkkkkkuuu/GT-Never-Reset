# Large Fragment World Collector

The structure pattern and processing multipliers are adapted from [GTLCore](https://github.com/GNSW/GTLCore) at commit `b6f3c1ecf04165d6445a570830a45a9bed8ee0f8`. The upstream LGPL version 3 license is included in `LICENSE.txt`.

The [GTL Enhanced campus machine catalog](https://github.com/hongshaotimo/GTL-Enhancedcore/blob/41f3a122bf01fb405fd4f33e161642a95503a7e4/src/main/resources/data/gtl_enhancedcore/worldgen/factory_campus_machines.json#L6355-L6420) records the Large Fragment World Collector as `gtceu:large_fragment_world_collection_machine` with dimensions 3 × 7 × 3. The [pattern](https://github.com/GNSW/GTLCore/blob/d76e55ab8f6a08d89cb5186bce7dc06aa9ce0c47/src/main/java/org/gtlcore/gtlcore/common/data/machines/structure/MultiBlockMachineBStructure.java#L7-L10) in its GTLCore dependency, 1.2.3.3-fix4, matches the imported pattern.

The source pattern is `LARGE_FRAGMENT_WORLD_COLLECTION_MACHINE` in [MultiBlockMachineBStructure.java](https://github.com/GNSW/GTLCore/blob/b6f3c1ecf04165d6445a570830a45a9bed8ee0f8/src/main/java/org/gtlcore/gtlcore/common/data/machines/structure/MultiBlockMachineBStructure.java). The GTNR MBS1 resource preserves the 3 × 7 × 3 geometry. It reverses the source rows and aisles, converts wildcard `A` to a space, and converts controller `S` to `~` at offset (1, 3, 0). The resource stores horizontal layers from top to bottom. The controller transposes them into front-to-back aisles for StructureLib.

The [upstream controller definition](https://github.com/GNSW/GTLCore/blob/d76e55ab8f6a08d89cb5186bce7dc06aa9ce0c47/src/main/java/org/gtlcore/gtlcore/common/data/machines/MultiBlockMachineB.java#L200-L225) uses one energy input, fixed item bus positions, 64 parallel operations, a duration multiplier of 0.25, and an energy multiplier of 256. The GTNR controller uses stable titanium casings, permits additional item inputs and fluid I/O in casing positions, and uses 64 independent recipe threads on the GTNR fragment collection recipe map. The GTNR port is available in normal worlds.

The GTNR controller recipe preserves the original 3 × 3 pattern, IV circuits, EV field generators, small collector and tungstensteel gearboxes. It uses the same substitutes for the two skyblock crystals as GTNR's small collector, an LV sensor for the treasures crystal and an LV emitter for the mining crystal. The original recipe is declared in [SkyTearsAndGregHeart.java](https://github.com/GNSW/GTLCore/blob/b6f3c1ecf04165d6445a570830a45a9bed8ee0f8/src/main/java/org/gtlcore/gtlcore/data/recipe/processing/SkyTearsAndGregHeart.java#L321-L327).

The front overlays come from [GregTech CEu Modern 1.20.1-1.4.4](https://github.com/GregTechCEu/GregTech-Modern/tree/e3844ba943e2388c0856617ae4f8b473a0ae1b64/src/main/resources/assets/gtceu/textures/block/multiblock/gcym/large_extractor), the renderer path named in the GTLCore controller definition. The six idle, active, paused and emissive PNGs and two animation metadata files were copied unchanged from the release JAR referenced by the GTL Enhanced pack and matched against the pinned sources. GTNR composites them over its stable titanium casing and selects the paused overlays using the machine's synchronized work switch. The upstream LGPL version 3 license is in `GTCEu-LICENSE.txt`.
