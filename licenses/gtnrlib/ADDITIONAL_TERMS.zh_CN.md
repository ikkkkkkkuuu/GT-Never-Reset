# GTNLLib 附加条款

> 本文为 [LICENSE-ADDITIONAL-TERMS.md](LICENSE-ADDITIONAL-TERMS.md) 的参考译文，两者不一致时以英文版为准。

GTNLLib 依据 GNU 通用公共许可证第 3 版（[LICENSE.txt](GPL-3.0.txt)）授权。对于其拥有版权且有权附加本条款的内容，GTNLLib 的版权持有人依据该许可证第 7 条 (b) 项附加本文件中的条款。

本条款仅要求保留特定的法律声明和作者署名，不剥夺 GNU GPL 第 3 版授予的任何权利。

## 1. 定义

- **受保护内容**：同时满足以下条件的 GTNLLib 代码和资源：
  - 由有权附加本条款的版权持有人创作或持有版权；
  - 其版权持有人明确将本条款应用于该内容。满足前一项条件的代码和资源，只要包含在 GTNLLib 仓库或其构建产物中，即视为其版权持有人已明确将本条款应用于该内容；仓库根目录的本文件，以及构建产物中随附的本文件，即为表明其适用范围的明确标记。

- **适当法律声明**：GNU GPL 第 3 版第 0 条所定义的 Appropriate Legal Notices。

- **署名**：第 3 条规定的 GTNLLib 项目作者署名。

- **你的作品**：你传播的、包含受保护内容或以其为基础的任何作品，无论是复制、修改、改名、重新打包还是内嵌打包（shade）。

## 2. 适用范围

本条款适用于所有受保护内容，无论这些内容通过 GitHub、CurseForge、Modrinth 或其他渠道公开，也无论它们以源代码、资源文件、构建产物或其他形式传播。

传播受保护内容时，必须保留适用于该内容的附加条款声明，并向接收者提供本文件及 GNU GPL 第 3 版的副本。

如果你的作品包含受保护内容，本条款仍适用于这些内容，不因你没有单独复制本文件而失效。受保护内容的适用范围以仓库根目录的本文件以及构建产物中随附的本文件为准，不需要在每个源文件中单独标记。

如果某个源文件中带有适用本条款的声明，或带有指向本文件的说明，传播时必须保留。例如：

```text
This file is subject to the additional terms in LICENSE-ADDITIONAL-TERMS.md.
```

来自其他项目的代码和资源，以及仅由它们衍生的内容，仍适用其各自的许可证，具体信息见 `src/main/resources/licenses` 和 `src/main/resources/META-INF/licenses` 下的许可证说明。即使它们随 GTNLLib 一同发布，本条款也不适用于它们，除非相关版权持有人另行明确授权。

## 3. 项目作者署名

你的作品必须在受保护内容本身中，或在包含受保护内容的作品所显示的适当法律声明中，保留以下项目作者署名：

> 包含来自 GTNLLib 的代码。项目作者包括 HFstudio、LineBroke 及其他贡献者。

GTNLLib 在游戏内模组列表的模组信息中显示其适当法律声明，其中包括上述署名。

对于你的作品，只要玩家能够通过模组信息或作品显示法律声明的其他界面（例如「关于」界面）找到并清晰阅读这条署名，即满足本条要求。

署名可以翻译。如果你修改了代码，可以调整措辞以保持准确，例如：

> 基于 GTNLLib 的代码。原项目作者包括 HFstudio、LineBroke 及其他贡献者。

如果某项修改导致原有署名不再准确，你应当合理调整署名，避免将他人的贡献错误归属于原项目作者，或将原项目作者的贡献错误归属于其他人。

本条不要求你逐字复制 GTNLLib 的其余法律声明。你的作品需要提供哪些法律声明，由 GNU GPL 第 3 版本身规定。

符合要求的 `mcmod.info` 写法示例：

```json
"credits": "Contains code from GTNLLib. Project authors include HFstudio, LineBroke and other contributors."
```

## 4. 本条款不要求的事项

本条款：

- 不适用于只将 GTNLLib 作为独立的前置库模组使用、且不包含任何受保护内容的作品；
- 不适用于你独立编写、没有复制受保护内容的功能，即使它的效果与 GTNLLib 相似；
- 不要求你保留项目链接、标志或其他宣传内容；
- 不要求你在下载页面、网站或你的作品以外的其他材料上署名；
- 不要求你采用 GTNLLib 的代码结构、命名方式、界面设计或其他实现方式。

除第 3 条规定的署名保留义务外，本条款不增加其他限制，不影响 GNU GPL 第 3 版授予的其他权利。

## 5. 请求

以下内容是项目方的请求，而不是许可证条件。我们希望你：

- 在署名旁边附上项目链接：https://github.com/GTNotLeisure/GTNLLib；
- 在分发作品的页面上（例如 CurseForge、Modrinth 或 GitHub Release 页面）注明 GTNLLib 及其作者；
- 考虑改为依赖 GTNLLib，而不是复制它的代码，以免玩家同时运行两份相同的代码；
- 等相关功能合并并正式发布后再复制，因为拉取请求中的未完成代码可能仍会发生变化，也可能包含尚未修复的问题。

上述请求均为自愿性质，不构成传播、修改或使用受保护内容的附加条件。

贡献者提交贡献前，应当能够明确知晓本条款的内容及其适用范围。项目方应保留能够证明相关贡献者同意适用本条款的记录。

本条款旨在依据 GNU GPL 第 3 版第 7 条 (b) 项，要求在受保护内容中，或在包含受保护内容的作品所显示的适当法律声明中，保留合理的法律声明和作者署名。
